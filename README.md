# problema-bancario-simulacion

Simulación de Colas – Banco de Colombia
Descripción

Este proyecto presenta una simulación del problema bancario propuesto para la asignatura de Simulación.

El objetivo consiste en determinar la mejor distribución de tres cajeros para atender dos tipos de operaciones:

Retiros (70 % de los usuarios)
Pagos y consignaciones (30 % de los usuarios)

Para el análisis se utilizó un modelo de colas M/M/1 y se ejecutaron 10 réplicas de simulación para comparar dos configuraciones:

Configuración A
1 cajero para retiros
2 cajeros para pagos
Configuración B
2 cajeros para retiros
1 cajero para pagos
Objetivos
Analizar los tiempos de atención por cajero.
Evaluar el promedio de usuarios atendidos.
Comparar los resultados de 10 réplicas de simulación.
Determinar la necesidad de un nuevo cajero.
Identificar la configuración óptima para el banco.
Tecnologías utilizadas
HTML5
CSS3
JavaScript
Chart.js
Resultados principales

La simulación permitió concluir que:

Los retiros representan la mayor carga operativa del sistema.
La configuración A genera congestión en el cajero de retiros.
La configuración B distribuye mejor la demanda.
No es necesario incorporar un cuarto cajero bajo las condiciones actuales.
La mejor alternativa es asignar 2 cajeros a retiros y 1 cajero a pagos.
